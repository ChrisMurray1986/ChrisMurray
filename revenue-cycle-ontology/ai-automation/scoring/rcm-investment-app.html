Optimized roadmap

A greedy budget-constrained scheduler: each quarter it funds the gate remediations that unlock the most net value per dollar, then launches every use case whose gates are clear, ranked by net value per build dollar. Deterministic and transparent — every scheduled item shows its reason. Assumed remediation costs/durations are listed under the roadmap.

Generated from the revenue-cycle ontology's driver files (gate-vectors, value-drivers, cost-drivers) — see revenue-cycle-ontology/ai-automation/. Engines are JavaScript ports of score.py / value.py / cost.py; the YAML drivers remain the source of truth (rebuild via build_app.py). Estimates use shared-pool capping, disposition-gated ramps, and TCO-based sourcing decisions; ranges and governance rules per files 07–11.
